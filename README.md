# KRASO Bílina

Nový web krasobruslařského klubu KRASO Bílina.

## Cíl projektu
- modernizace původního webu
- přehledná prezentace klubu
- nábor nových členů
- informace o tréninkových skupinách
- závody, výsledky a Bílinská bruslička
- responzivní zobrazení pro mobil a desktop
- příprava pro lokální SEO a vlastní doménu

## Technologie
Statický HTML/CSS/JavaScript web připravený pro GitHub Pages.

## Stav
První designová verze. Obsah a kontaktní údaje budou dále migrovány a ověřeny podle původního webu KRASO Bílina.
